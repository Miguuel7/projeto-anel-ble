# 02.2 - Como ligar o botão ao MDBT42V

## Ligação mínima

```txt
Pino GPIO do MDBT42V
↓
Botão tátil SMD
↓
GND
```

## Como funciona

O botão fica aberto normalmente.

Quando a pessoa pressiona:

```txt
GPIO encosta no GND
↓
Firmware detecta LOW
↓
MDBT42V envia alerta BLE
```

## No firmware

Configurar o GPIO como entrada com pull-up interno.

```txt
Botão solto = HIGH
Botão pressionado = LOW
```

## Para leigos

Pensa no botão como uma ponte.

- Solto: ponte aberta.
- Pressionado: ponte fecha e liga o pino ao GND.

## Teste simples

Antes de colocar na carcaça:

1. Medir continuidade com multímetro.
2. Botão solto: sem continuidade.
3. Botão apertado: com continuidade.
4. Testar se o firmware detecta o clique.
