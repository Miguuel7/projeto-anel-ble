# 00.1 - Início do projeto

Este vault organiza o projeto do **Anel BLE de Pânico** para uma equipe de até **18 pessoas leigas**, separando o trabalho por partes simples.

## Ideia principal

O anel **não faz tudo sozinho**.

Ele funciona como um **gatilho Bluetooth Low Energy (BLE)**:

```txt
Usuário pressiona o botão
↓
MDBT42V-512KV2 acorda
↓
Envia sinal BLE para o celular
↓
Aplicativo recebe o sinal
↓
Aplicativo executa localização, mensagem, chamada e alerta
```

## Versão do projeto

Esta versão é a **mínima funcional**:

- sem LED;
- sem vibração;
- sem GPS;
- sem GSM;
- sem microfone;
- sem cartão SD;
- sem USB-C;
- com carregamento por contatos magnéticos;
- com bateria Li-Po flexível;
- com PCB rigid-flex;
- com carcaça única.
