# 10.3 - Perguntas para fornecedores

## Para fornecedor de PCB

```txt
Olá! Preciso fabricar uma PCB rigid-flex pequena para um protótipo de anel BLE.

A placa precisa ter:
- área rígida para módulo MDBT42V-512KV2;
- parte flexível em poliimida;
- pads para botão SMD;
- pads para bateria Li-Po flexível;
- pads para contatos de carga;
- pads SWD;
- montagem SMD opcional.

Vocês fazem esse tipo de PCB? Qual o mínimo de unidades, prazo e custo?
```

## Para fornecedor de bateria

```txt
Olá! Preciso de uma bateria Li-Po flexível 3.7V para um protótipo pequeno.

Procuro algo entre 15 e 30 mAh, fino, flexível e seguro.

A bateria possui proteção integrada?
Qual a espessura?
Qual o raio mínimo de curvatura?
Qual a corrente máxima de carga recomendada?
```

## Para fornecedor de carcaça

```txt
Olá! Preciso prototipar uma carcaça de anel eletrônico com canal interno.

A peça precisa acomodar:
- PCB rigid-flex;
- bateria Li-Po flexível;
- botão SMD;
- contatos magnéticos de carga.

Vocês fazem protótipo em resina, nylon ou PC/ABS?
Qual precisão e tolerância conseguem?
```
