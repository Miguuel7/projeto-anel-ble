# 09.3 - Checklist de entrega da linha de montagem

Este checklist serve para controlar a entrega de cada estação.

---

## Estação 1 — Peças e medidas

- [ ] Peças conferidas.
- [ ] Medidas conferidas.
- [ ] Peças erradas separadas.
- [ ] Lista de faltantes registrada.
- [ ] Peças liberadas para montagem.

---

## Estação 2 — PCB

- [ ] PCB inspecionada.
- [ ] PCB limpa.
- [ ] Pads conferidos.
- [ ] Trilhas conferidas.
- [ ] Área flexível aprovada.
- [ ] PCB liberada para soldagem.

---

## Estação 3 — Soldagem BLE e passivos

- [ ] MDBT42V soldado.
- [ ] Capacitores soldados.
- [ ] Solda inspecionada.
- [ ] Sem curto entre VCC e GND.
- [ ] Placa liberada para botão.

---

## Estação 4 — Botão

- [ ] Botão soldado.
- [ ] Botão clica corretamente.
- [ ] Continuidade testada.
- [ ] GPIO validado.
- [ ] Placa liberada para energia.

---

## Estação 5 — Energia

- [ ] Proteção soldada.
- [ ] Bateria medida.
- [ ] Bateria conectada.
- [ ] Saída protegida medida.
- [ ] Sem aquecimento.
- [ ] Placa liberada para carregamento.

---

## Estação 6 — Carregamento

- [ ] Carregador soldado.
- [ ] Resistor PROG soldado.
- [ ] Contatos de carga instalados.
- [ ] Polaridade conferida.
- [ ] Carregamento testado.
- [ ] Placa liberada para firmware.

---

## Estação 7 — Programação e BLE

- [ ] Firmware gravado.
- [ ] Botão detectado.
- [ ] BLE aparece no celular.
- [ ] App recebe evento.
- [ ] Placa liberada para carcaça.

---

## Estação 8 — Carcaça

- [ ] Carcaça revisada.
- [ ] PCB inserida.
- [ ] Bateria sem pressão.
- [ ] Botão alinhado.
- [ ] Contatos alinhados.
- [ ] Anel liberado para teste final.

---

## Estação 9 — Qualidade final

- [ ] Teste elétrico aprovado.
- [ ] Teste de carga aprovado.
- [ ] Teste BLE aprovado.
- [ ] Teste do app aprovado.
- [ ] Teste mecânico aprovado.
- [ ] Produto aprovado.
- [ ] Produto reprovado, se houver falha.

---

## Regra final

Se qualquer item crítico falhar, o anel volta para a estação responsável.

Não passa adiante no “vai dar”.
