# 07.1 - Linha de montagem completa

Este documento explica a linha de montagem do anel BLE de pânico.

## Imagem de referência

![[Assets/linha_de_montagem_anel_ble.png]]

## Etapa 1 — Fabricação da PCB

Responsável por:

- fabricar a [[01 - Placa/01.2 - PCB rigid-flex]];
- criar área rígida para o [[01 - Placa/01.1 - MDBT42V-512KV2]];
- criar trilhas flexíveis;
- criar pads dos contatos magnéticos;
- criar pads SWD.

Resultado esperado:

```txt
PCB pronta, sem componentes soldados
```

## Etapa 2 — Soldagem SMD dos componentes

Soldar:

- [[01 - Placa/01.1 - MDBT42V-512KV2]]
- [[01 - Placa/01.3 - Capacitores SMD]]
- [[04 - Carregamento/04.1 - Carregador Li-Po]]
- [[04 - Carregamento/04.2 - Resistor de programação do carregador]]
- [[03 - Energia/03.2 - Proteção da bateria]]

Resultado esperado:

```txt
PCB com circuito principal soldado
```

## Etapa 3 — Instalação do botão

Soldar o [[02 - Acionamento/02.1 - Botão tátil SMD]].

Resultado esperado:

```txt
Botão clicando e conectado ao GPIO
```

## Etapa 4 — Conexão da bateria

Conectar a [[03 - Energia/03.1 - Bateria Li-Po flexível]].

Resultado esperado:

```txt
Circuito alimentado por bateria
```

## Etapa 5 — Instalação dos contatos de carga

Instalar [[04 - Carregamento/04.3 - Contatos de carga magnética]].

Resultado esperado:

```txt
Anel pode receber 5 V pela base magnética
```

## Etapa 6 — Inserção na carcaça

Inserir conjunto eletrônico dentro da [[05 - Carcaça 3D/05.1 - Carcaça única do anel]].

Resultado esperado:

```txt
Eletrônica alinhada dentro do anel
```

## Etapa 7 — Fechamento e acabamento

Selar ou finalizar a carcaça.

Resultado esperado:

```txt
Anel fechado, confortável e sem peças soltas
```
