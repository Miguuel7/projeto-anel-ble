# 07.4 - Checklist de montagem

## Placa

- [ ] PCB sem dano visual
- [ ] Trilhas sem rompimento
- [ ] Pads SWD acessíveis
- [ ] Componentes alinhados
- [ ] Sem curto entre VCC e GND

## Botão

- [ ] Botão soldado
- [ ] Botão clica
- [ ] Botão não fica preso
- [ ] Botão detectado pelo firmware

## Energia

- [ ] Bateria sem estufamento
- [ ] Bateria com polaridade correta
- [ ] Proteção ligada corretamente
- [ ] Tensão medida antes de ligar

## Carregamento

- [ ] Contatos magnéticos alinhados
- [ ] MCP73831/MCP73832 soldado
- [ ] Resistor PROG soldado
- [ ] Carga com corrente baixa
- [ ] Bateria não esquenta carregando

## Carcaça

- [ ] Bateria não está prensada
- [ ] PCB não está forçada
- [ ] Botão funciona pela carcaça
- [ ] Contatos externos acessíveis
- [ ] Anel confortável

## BLE

- [ ] Celular encontra o anel
- [ ] App pareia
- [ ] Botão envia evento
- [ ] App executa alerta

## Aprovação

- [ ] Teste elétrico aprovado
- [ ] Teste de carga aprovado
- [ ] Teste BLE aprovado
- [ ] Teste mecânico aprovado
