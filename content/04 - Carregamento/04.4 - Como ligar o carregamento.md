# 04.4 - Como ligar o carregamento

## Fluxo de carregamento

```txt
Base de carga 5 V
↓
Contatos de carga magnética
↓
MCP73831/MCP73832
↓
Bateria Li-Po flexível
```

## Ligações

```txt
Pogo + → VDD do MCP73831/MCP73832
Pogo - → GND

BAT do MCP73831/MCP73832 → Bateria +
GND do MCP73831/MCP73832 → Bateria -

PROG → Resistor PROG → GND
```

## Corrente de carga

Para bateria pequena, usar corrente baixa:

```txt
5 mA a 15 mA
```

## Teste de carregamento

1. Conectar base de carga.
2. Verificar se chega 5 V nos contatos.
3. Medir tensão no BAT do carregador.
4. Confirmar que a bateria não esquenta.
5. Verificar se a tensão sobe lentamente.

## Erros proibidos

- Inverter contato positivo e negativo.
- Usar carregador sem resistor PROG.
- Carregar bateria pequena com corrente alta.
- Carregar bateria danificada ou estufada.
