# 08.3 - Teste BLE

## Objetivo

Confirmar que o anel envia sinal Bluetooth para o celular.

## Passos

1. Gravar o [[06 - Software/06.1 - Firmware do MDBT42V]].
2. Abrir o [[06 - Software/06.2 - Aplicativo do celular]].
3. Procurar dispositivo BLE.
4. Parear ou reconhecer o anel.
5. Pressionar o botão.
6. Confirmar recebimento do evento.

## Evento esperado

```json
{
  "device_id": "ANEL-001",
  "event": "panic",
  "press_type": "long_press"
}
```

## Reprovar se

- Celular não encontra o dispositivo.
- Botão não gera evento.
- Evento chega errado.
- BLE falha dentro da carcaça.
- Alcance é muito baixo.

## Observação

Testar primeiro fora da carcaça e depois dentro dela.
