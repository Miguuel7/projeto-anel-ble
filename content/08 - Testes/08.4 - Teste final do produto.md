# 08.4 - Teste final do produto

## Objetivo

Testar o anel como se fosse uso real.

## Checklist final

- [ ] Botão funciona pela carcaça.
- [ ] App recebe o sinal.
- [ ] App envia localização.
- [ ] App envia mensagem.
- [ ] App faz chamada, se configurado.
- [ ] Carregamento magnético funciona.
- [ ] Bateria não esquenta.
- [ ] Anel é confortável.
- [ ] Contatos de carga não machucam.
- [ ] BLE funciona com o celular no bolso.

## Teste de falso acionamento

1. Usar o anel por alguns minutos.
2. Mexer a mão normalmente.
3. Verificar se ele dispara sozinho.
4. Ajustar tempo de clique no firmware.

## Teste de emergência simulada

1. Pressionar botão por tempo definido.
2. Confirmar alerta no app.
3. Confirmar envio aos contatos de teste.
4. Cancelar alerta.

## Aprovação

Produto aprovado somente se:

```txt
Botão funciona
BLE funciona
Carga funciona
Bateria segura
Carcaça confortável
App executa alerta
```
