# 06.1 - Firmware do MDBT42V

**Item:** firmware BLE para nRF52832  
**Função:** controlar o botão, economia de energia e envio do sinal Bluetooth.

## Funções principais

- Ler o [[02 - Acionamento/02.1 - Botão tátil SMD]]
- Usar GPIO com pull-up interno
- Detectar clique longo
- Acordar o [[01 - Placa/01.1 - MDBT42V-512KV2]]
- Enviar evento BLE para o celular
- Voltar para modo de baixo consumo

## Funcionamento

```txt
Usuário pressiona o botão
↓
MDBT42V acorda
↓
Firmware detecta o evento
↓
Envia sinal BLE
↓
Celular recebe
↓
MDBT42V volta a dormir
```

## Evento BLE

```json
{
  "device_id": "ANEL-001",
  "event": "panic",
  "press_type": "long_press"
}
```

## Configuração do botão

```txt
GPIO com pull-up interno
Solto = HIGH
Pressionado = LOW
```

## Regras

- Ignorar toques muito curtos.
- Priorizar toque longo para evitar falso acionamento.
- Voltar a dormir após enviar o alerta.
- Manter consumo baixo.
