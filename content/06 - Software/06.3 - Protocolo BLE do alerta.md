# 06.3 - Protocolo BLE do alerta

## Objetivo

Definir o tipo de mensagem enviada pelo anel para o celular.

## Mensagem mínima

```json
{
  "device_id": "ANEL-001",
  "event": "panic",
  "press_type": "long_press"
}
```

## Campos

### device_id

Identifica qual anel enviou o alerta.

Exemplo:

```txt
ANEL-001
```

### event

Define o tipo de evento.

Exemplo:

```txt
panic
```

### press_type

Define o tipo de pressão.

Exemplos:

```txt
short_press
long_press
double_press
```

## Versão inicial recomendada

Usar apenas:

```txt
long_press = alerta real
```

Isso reduz falso acionamento.

## Fluxo BLE

```txt
MDBT42V anuncia/pareia
↓
App reconhece o dispositivo
↓
Botão é pressionado
↓
MDBT42V envia evento
↓
App executa alerta
```

## Observação

Para a primeira versão, não precisa mandar dados grandes.  
O app faz todo o resto.
